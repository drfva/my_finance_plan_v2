# Собственный план при входе и переключение

При входе и обновлении страницы приложение всегда открывает собственный личный план с ролью владельца. Сохранённый параметр `plan` больше не выбирает общий, семейный или другой ранее открытый план. После загрузки адрес обновляется ID выбранного личного плана. Переключение на остальные доступные планы остаётся в «Настройки → План».

`bootstrap_user` под блокировкой по пользователю выбирает личный план с ролью `owner`; среди таких планов сначала выбирает созданный самим пользователем, затем самый ранний по дате участия. Если собственного плана нет, создаёт его с обычными начальными настройками. Доступ к чужому плану, выданный до первого входа, и членство в семье не препятствуют созданию. Повторные входы не создают дубликаты, роли и данные существующих планов сохраняются.

При быстрых повторных переключениях применяется только последний выбор: запоздалый ответ предыдущего запроса не открывает другой план. Выбор уже открытого плана отменяет незавершённый переход. Ответ проверяется на соответствие запрошенному ID.

Сетевой сбой вида Safari `Load failed` повторяет только чтение выбранного плана, один раз. Ошибки прав доступа и SQL не повторяются. Если связь не восстановилась, открытый план сохраняется и показывается понятное сообщение с предложением повторить выбор. Повторная загрузка не обходит проверку прав. Сам Safari в локальной среде не запускается; сетевой ответ и выброшенный `TypeError` проверяются автотестами.

## Применение

В SQL Editor каждой используемой базы выполнить целиком `supabase/migrations/20261102084138_personal_plan_startup.sql`, затем опубликовать файлы сайта. Миграция требует предыдущие миграции с типами личных и семейных планов. Новая Edge Function и повторная сборка worker не нужны. Для чистой базы обновлён `v2/install.sql`.

## Проверка

- `node --test tests/*.test.mjs` — выбор при старой ссылке, отмена перехода, порядок ответов и сетевые сбои.
- `node --test tests/personal-startup.database.mjs` — чистая установка, выдача доступа до первого входа, отдельный собственный план, переход в общий и обратно, сохранение данных и проверка прав в настоящем SQL/PGlite.
- `tools/preview/family-server.mjs` — локальный предпросмотр с вымышленными пользователями: Саше и гостю общий доступ к плану Анны выдаётся до первого входа. Саша — редактор, гость — читатель; каждый получает свой личный план.
