# Модель процентных выплат

В графике года выбирается `plan_years.salary_model`: `worked_days` по умолчанию либо `percentage`. В слотах процентной модели задаётся `salary_percent` (0–100). SQL ограничивает сумму по году сверху 100%, браузер требует ровно 100% для генерации. Незавершённый график можно сохранить; автоматические суммы показывают предупреждение и не фиксируются сервером или браузером.

Предыдущие выплаты начисляют свой процент оклада с поправкой на отработанную долю рабочих дней своего периода. Последняя определяется датами выплат графика (с учётом переносов), относится к расчётному месяцу и получает остаток фактического месячного оклада. Начисления ведутся до налога, затем применяется существующий налоговый движок по датам выплат и накопленной базе. Отпуска и больничные добавляются прежним способом, отдельно от окладного остатка. Разовые выплаты в остаток не входят.

Ручные/закреплённые предыдущие окладные выплаты засчитываются по фактической сумме. Оклады с изменением ставки внутри месяца учитываются по датам. Предыдущие выплаты выше месячного начисления дают предупреждение и нулевой остаток; автоматическая фиксация ожидает исправления. Снимки закреплённых выплат не переписываются.

В личном Обзоре расходов теперь есть статьи/подкатегории и средний план/факт за месяц = годовая сумма / 12. Детализация использует тот же расчёт долей статей, что месячные Расходы, с учётом ручной суммы выплаты, процентов и сезонов. Удалённые статьи с фактом сохраняются в детализации; общий факт родителя показан отдельно.

Применение: выполнить `supabase/migrations/20261102134547_percentage_salary.sql` в каждой базе, опубликовать сайт. Для чистой базы обновлён `v2/install.sql`. Общий движок изменился: перед развёртыванием `family-worker` выполнить `node tools/build-family-function.mjs`, затем переопубликовать функцию для каждой базы.

В сентябре 2026 отпуск 20–24 числа исключает четыре рабочих дня стандартной пятидневки. Для 17 отработанных дней из 22 отпуск должен также включать 25 сентября либо календарь должен содержать соответствующие исключения. Расчёт не подменяет календарь числами примера.
