# Цели: закрытие, архив и Обзор

В Копилках и Подушках есть три независимых действия:

- **Закрыть цель** — остановить распределение и прогнозы. Приоритет становится `NULL`, остальные активные цели своего типа получают последовательные номера. Снимок `completion_snapshot` сохраняет прогресс на дату закрытия, дальнейшие движения меняют баланс.
- **В архив** — убрать закрытую цель из основного списка Копилок или Подушек. Кнопка «Архив» открывает отдельный список. «Вернуть из архива» сохраняет цель закрытой. «Вернуть в работу» очищает снимок, снимает архив и ставит цель в конец очереди активных целей своего типа.
- **Глазик в Обзоре** — скрыть отдельную цель только с Обзора. Кнопка «Показать на Обзоре» есть у скрытой цели в Копилках/Подушках, включая архив. Скрытие не меняет расчёты. Архив и закрытие сами по себе не скрывают цель с Обзора.

Архив (`archived`) и скрытие с Обзора (`hidden_overview`) сохраняются вместе с целью в плане и действуют для всех его участников и годов. Просмотр архива доступен читателю; изменение состояний — только участнику с правом редактирования.

У закрытых целей ручные отчисления сохраняют историю до даты закрытия включительно, но игнорируются в будущих выплатах. Если старый снимок отсутствует, до его создания сохраняются только прошедшие зафиксированные выплаты. Исходные ручные суммы не удаляются, поэтому снова действуют после возврата в работу.

В сводной плашке карточки показывается этап с ближайшей датой срока или прогноза от текущего дня включительно. Прошедшие даты пропускаются. Если будущих дат нет, сводная плашка отсутствует. Если хотя бы один этап имеет оранжевый статус «позже срока», вся активная карточка получает оранжевую рамку и предупреждение в шапке. Метка «потрачено» у целей и этапов не выводится.

## Обновление базы

Перед обновлением приложения выполнить `v2/sql/007_goal_archive.sql` в SQL Editor нужного проекта Supabase. Требуется ранее выполненный `006_goal_completion.sql`. Скрипт добавляет два флага с умолчанием `false`, разрешает отсутствие приоритета и снимает приоритет у уже закрытых целей.

Для чистой базы обновлённый `v2/install.sql` включает оба скрипта. На существующей базе использовать отдельный скрипт обновления.
