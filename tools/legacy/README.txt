Сверка движка v2 со старой версией.

  old.mjs      загружает логику старого index.html в песочницу Node (без браузера и базы)
  convert.mjs  переводит старое состояние в формат v2 — прообраз скрипта переноса (этап 6)
  compare.mjs  прогоняет несколько планов через обе версии и сравнивает по каждой выплате:
               доход, расходы, суммы в цели, погашения карт, балансы копилок, даты этапов

Запуск: положить старый index.html (из ветки main) сюда под именем old.html и выполнить
  node tools/legacy/compare.mjs

Порядок этапов в convert.mjs выставлен как в старой версии (подарки после кредитов),
иначе результаты законно разойдутся: в v2 по умолчанию подарки идут вторым этапом.
