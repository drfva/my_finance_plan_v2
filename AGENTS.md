# Правила работы с проектом

## Пользовательское руководство

Пользователь попросил поддерживать руководство актуальным при последующих изменениях проекта.

- Основной пользовательский документ — `help/index.html`. Это самостоятельная HTML-страница, доступная по значку вопроса в шапке приложения. Технические документы в `docs/` не заменяют обновление руководства.
- При изменении пользовательских действий, названий кнопок, навигации, расчётов, доступа или ограничений обновлять соответствующий раздел руководства в той же работе. Указывать дату актуализации. Не описывать ещё не реализованные возможности как доступные.
- При заметном изменении показанного интерфейса обновлять затронутые скриншоты в `help/images/`, подписи и альтернативный текст. Использовать только вымышленные данные локального предпросмотра. Не помещать в публикуемые файлы реальные финансовые данные, почту, токены, ключи и приглашения.
- Инструкции по поддержке и проверке — `docs/user-guide-maintenance.md`. Проверять ссылки, изображения и открытие справки с адреса GitHub Pages с префиксом репозитория.
- Если правка не влияет на пользовательское поведение или показанный интерфейс, не менять руководство искусственно; достаточно отметить это в результате работы при необходимости.
