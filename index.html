Вход

Пришлём на почту ссылку для смены пароля. Перейдёте по ней — вернётесь сюда и зададите новый пароль.
Откройте письмо и перейдите по ссылке — вернётесь сюда уже с правом сменить пароль. Эту вкладку можно закрыть.
Если в письме пришёл код (так бывает, когда подключён свой SMTP), введите его здесь вместе с новым паролем.
Вы перешли по ссылке из письма. Задайте новый пароль.
